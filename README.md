# Road Book Assistant

**Du premier zébra à la dernière flèche.**

Road Book Assistant (RBA) est un logiciel Windows gratuit pour créer les road books et le cahier de sécurité
d'une épreuve de rallye : tulipes, PK et dégressif calculés tout seuls, pictogrammes RTS FFSA, vérification
automatique, fiches de poste, tableau de synthèse et PDF prêts à imprimer.

Conçu par et pour les bénévoles du **Rallye des Cimes** (Écurie des Cimes).

## Télécharger

👉 Ouvre **[Releases](../../releases/latest)** et télécharge le fichier `Installer_Road_Book_Assistant_….exe`.

- Windows 10 ou 11, aucun droit administrateur nécessaire.
- Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » :
  clique sur **Informations complémentaires › Exécuter quand même**.
- Les mises à jour se font ensuite **toutes seules** : RBA te prévient au démarrage.

## Tes projets

Les projets s'enregistrent en fichiers `.rba` dans `Documents\Road Book Assistant`.
Un double-clic sur un fichier `.rba` ouvre directement le projet.

## Pour apprendre

Dans RBA : menu **Aide › Formation** (8 modules guidés) et **Aide › Afficher les aides**.
